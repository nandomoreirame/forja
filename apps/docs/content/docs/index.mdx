# Welcome to Forja

Forja is an open-source desktop GUI client for AI coding CLIs like **Claude Code**, **Gemini CLI**, and **Codex CLI**. Instead of a raw terminal, you get a dedicated interface with rich rendering, multi-session management, and deep project integration.

![Forja — Workspaces with Projects](/screenshots/0.workspaces-with-projects.png)

## What Forja does

| Feature | Description |
|---------|-------------|
| **Enhanced Rendering** | Markdown and code blocks rendered with syntax highlighting |
| **Multi-Session Tabs** | Multiple concurrent AI sessions per project |
| **File Tree & Preview** | Browse files with git status badges and syntax-highlighted preview |
| **Git Integration** | Branch, modified files, diff viewer — always visible |
| **Embedded Browser** | In-app browser that auto-opens on localhost URLs |
| **14+ Themes** | Catppuccin, Dracula, Nord, Tokyo Night, and more |
| **Workspaces** | Group projects into named workspaces |
| **External API** | Control Forja from scripts, hooks, and Discord |

## Supported CLIs

- [Claude Code](https://claude.ai/code)
- [Gemini CLI](https://github.com/google-gemini/gemini-cli)
- [Codex CLI](https://github.com/openai/codex)
- [Cursor Agent](https://cursor.sh) — via cursor binary
- Plain terminal — bash, zsh, fish
