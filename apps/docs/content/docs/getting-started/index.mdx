# Getting Started

Forja is a desktop GUI client that wraps AI coding CLIs — Claude Code, Gemini CLI, Codex CLI, and Cursor Agent — in a purpose-built interface. Instead of a raw terminal window, you get rich markdown rendering, multi-session tabs, an embedded file tree with git status, and an in-app browser, all without changing how the CLI itself works.

## How it works

Forja acts as a graphical shell around your existing AI CLI installation. When you start a session, Forja spawns the CLI process via a PTY (pseudo-terminal), streams its output back to the renderer, and displays it as formatted markdown with syntax-highlighted code blocks. The CLI communicates with its own cloud API directly — Forja never sees or stores your API keys.

If you already have Claude Code (or another supported CLI) installed and configured, you are ready to go.
