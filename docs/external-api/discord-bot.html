Discord Bot

Control Forja from a Discord server using slash commands and message prefixes via the forja-bot script powered by Discord.js 14.

Discord Bot

The Forja Discord bot (scripts/forja-bot) lets you control a running Forja instance from any Discord channel. It uses Discord.js 14 and communicates with the desktop app via the same Unix socket / named pipe as the CLI client.

This is useful for monitoring long-running AI sessions, triggering commands remotely, or getting notified about session events while away from your desk.

The Discord bot is a separate script — it is not bundled inside the Forja application. It must be started manually and requires a Discord bot token.

Prerequisites

  • Node.js 22 or newer
  • A Discord application with a bot user (Discord Developer Portal)
  • The bot must be invited to your server with bot and applications.commands scopes
  • Forja must be running on the same machine as the bot script

Setup

1. Create a Discord bot

  1. Go to the Discord Developer Portal.
  2. Click New Application and give it a name (e.g. "Forja").
  3. Navigate to Bot and click Add Bot.
  4. Under Privileged Gateway Intents, enable Message Content Intent.
  5. Copy the bot token from the Bot page.

2. Invite the bot to your server

Generate an invite URL from OAuth2 > URL Generator with the following scopes and permissions:

  • Scopes: bot, applications.commands
  • Bot permissions: Send Messages, Read Messages/View Channels

4. Start the bot

The bot will register slash commands globally and log in. Slash commands may take up to an hour to propagate to all servers after first registration.

Slash commands

Once the bot is online, the following slash commands are available in any channel it has access to:

CommandDescription
/forja-pingCheck if Forja is running and get the version
/forja-sessionsList all active PTY sessions
/forja-projectsList all open projects
/forja-project [number]List projects or switch to project N
/forja-output tabid:<id>Get the last output buffer of a session
/forja-send tabid:<id> text:<text>Send input to a terminal session
/forja-new-session type:<type>Start a new session (claude, codex, gemini, gh-copilot, terminal)

Discord bot vs webhook notifications

Forja supports two distinct Discord integrations with different purposes:

FeatureDiscord BotWebhook Notifications
SetupBot application + tokenWebhook URL only
DirectionBidirectional (send + receive)Outbound only
CommandsFull command setN/A
Use caseRemote controlEvent alerts
Configured in.env / environmentSettings > Notifications

Webhook notifications (configured at Settings > Notifications) send one-way alerts to a Discord channel when sessions start or finish. The bot integration provides full bidirectional control.

Both can be used simultaneously — they are independent.
