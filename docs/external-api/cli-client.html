CLI Client

Use the forja command-line client to control a running Forja desktop app from your terminal, shell scripts, or CI/CD pipelines.

CLI Client

The forja CLI is a thin shell wrapper around scripts/forja-cli.js that communicates with the running Forja desktop application via the External API.

Installation

The CLI is included in the Forja repository under scripts/. To make it globally available, add the scripts/ directory to your PATH, or create a symlink:

The CLI requires Node.js 22 or newer. The forja shell script delegates to forja-cli.js automatically.

Commands

ping

Check whether Forja is currently running and get the version number.

sessions

List all active terminal sessions with their tab IDs, project paths, and session types.

projects

List all projects that are currently open in Forja.

project [N]

Without an argument, lists all projects. With a numeric argument, switches Forja focus to that project (1-based index).

send <tabId> <text>

Send text input to an active session. The tab ID is obtained from forja sessions.

The text is automatically terminated with a carriage return (\r) so the command executes immediately.

output <tabId>

Retrieve the current output buffer of a session. Useful for capturing the last output from a running AI session.

new-session <type> [path]

Start a new session inside Forja. Valid session types are claude, codex, gemini, gh-copilot, and terminal.

notify <message>

Display a notification message inside the Forja application.

screenshot

Take a screenshot of the Forja window and receive the image data.

open-project <path>

Open a project directory in Forja.
