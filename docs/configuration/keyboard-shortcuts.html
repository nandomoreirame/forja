Keyboard Shortcuts

Complete reference for all Forja keyboard shortcuts organized by category — general, sessions, terminal, and layout.

Keyboard Shortcuts

All keyboard shortcuts use the Ctrl modifier on Linux and Windows. On macOS, substitute Ctrl with Cmd where applicable.

General

ShortcutAction
Ctrl+,Open Settings
Ctrl+POpen file search
Ctrl+Shift+POpen command palette
F11Toggle fullscreen

Sessions

Manage terminal tabs and switch between open projects.

ShortcutAction
Ctrl+TNew tab (session)
Ctrl+WClose current tab
Ctrl+TabSwitch to next tab
Ctrl+Shift+TabSwitch to previous tab
Ctrl+Shift+1Switch to project 1
Ctrl+Shift+2Switch to project 2
Ctrl+Shift+3Switch to project 3
Ctrl+Shift+4Switch to project 4
Ctrl+Shift+5Switch to project 5
Ctrl+Shift+6Switch to project 6
Ctrl+Shift+7Switch to project 7
Ctrl+Shift+8Switch to project 8
Ctrl+Shift+9Switch to project 9

Terminal

Shortcuts active when a terminal pane is focused.

ShortcutAction
Ctrl+CCopy selected text
Ctrl+VPaste from clipboard
Ctrl++Zoom in (increase terminal font size)
Ctrl+-Zoom out (decrease terminal font size)
Ctrl+0Reset terminal zoom to default

Ctrl+C in the terminal copies selected text when text is selected, and sends an interrupt signal (SIGINT) to the running process otherwise. This matches the behavior of most native terminal emulators.

Layout

Manage pane layout, visibility, and focus.

ShortcutAction
Ctrl+\Split pane vertically
Ctrl+Shift+\Split pane horizontally
Ctrl+Shift+BToggle file tree sidebar
Ctrl+Alt+FToggle focus mode (hide all chrome)

Customizing shortcuts

Keyboard shortcuts are not currently configurable via the UI. They are defined in the Electron main process and the frontend key handler layer.

If you need to remap shortcuts, you can contribute a configuration option — see Contributing for how to get started.
