Themes

Forja ships with 14 built-in themes covering a range of dark and light styles. Themes are applied via CSS custom properties and affect the entire application — the UI, the terminal, the editor, and the markdown renderer.

Switching themes

Settings dialog

  1. Open settings with Ctrl+,.
  2. Navigate to Appearance > Theme.
  3. Select a theme from the dropdown — the preview updates in real time.

Command Palette

  1. Open the command palette with Ctrl+Shift+P.
  2. Type theme to filter to theme commands.
  3. Select Change Theme and pick from the list.

The selected theme is saved to settings.json as the theme key and restored on next launch.

Brand color

Forja's brand color is #cba6f7 (Catppuccin Mauve). It is used sparingly for:

  • Selected items and active states
  • Primary call-to-action buttons
  • Highlights and focus rings
  • The application icon accent

All themes apply this color via the --ctp-mauve CSS variable, ensuring consistent branding regardless of the base palette.

Font groups

Forja uses three independent font groups, each configurable in settings:

GroupDefault fontFallbackDefault sizeUsed for
App UIGeist SansInter, system-ui14pxNavigation, panels, menus, labels
EditorJetBrains MonoFira Code, Menlo, monospace13pxMonaco editor, inline code, file preview
TerminalJetBrains MonoFira Code, Menlo, monospace14pxxterm.js terminal sessions

Font names must match the exact name of an installed system font or a web font loaded by Forja. If the specified font is not available, the fallback chain is used.

Change fonts and sizes via Settings (Ctrl+,) > Appearance.

Theme structure

Each theme is defined as a set of CSS custom properties applied to :root. The properties follow the Catppuccin naming convention (--ctp-*) supplemented by semantic aliases.

Theme definitions live in frontend/themes/ in the desktop app source:

FilePurpose
index.tsTheme registry — maps theme IDs to theme objects
apply.tsRuntime CSS variable injection
schema.tsTypeScript type definitions for theme shape
